### 🔑 Особенности

* **Math Unlock** — динамическая генерация математических примеров для разблокировки экрана.
* **Full Screen UI** — полноэкранное перекрытие окон с кастомным курсором.
* **Anti-Close** — блокировка базовых системных комбинаций клавиш и Диспетчера задач.
* **System Monitor** — отображение загрузки CPU/RAM в реальном времени через `psutil`.
* **Audio Background** — фоновое воспроизведение звукового сопровождения.

### 🛠️ Использованные библиотеки

* **GUI:** `tkinter`
* **Win32 API & Реестр:** `ctypes`, `winreg`
* **Система и ввод:** `keyboard`, `psutil`, `playsound`
